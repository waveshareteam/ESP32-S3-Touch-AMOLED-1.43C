# ESP32-S3-Touch-AMOLED-1.43C 出厂桌面

[English](README.md) | [简体中文](README_ZH.md)

## 功能

466 × 466 圆形桌面，每页 4 个图标，共 9 个 APP。小智集成在同一固件内，使用双麦克风与回放参考进行语音前处理。

| APP | 操作 |
| --- | --- |
| Display Test | 每秒切换红、绿、蓝、黄、白；双击屏幕任意位置或按 BOOT 退出。 |
| 设置 | 调节亮度、音量，配置 Wi-Fi、扫描网络或查看设备信息。 |
| 小智 / AIChats | 如提示激活，按屏幕说明操作；说“你好小智”或点击 Talk 对话，也可通过语音调节音量和亮度。 |
| 触摸测试 | 用手指绘画，可清空画布；通过返回按钮或 BOOT 退出。 |
| 天气 | 联网后刷新当前城市天气；默认城市为深圳。 |
| 音乐 | 播放或暂停内置演示音频；上一首、下一首会重新播放同一曲目，无需 SD 卡。 |
| 2048 | 滑动合并相同数字，通过屏幕按钮重新开始或返回。 |
| Mic Test | 观察 MIC1/MIC2 独立电平，最长录音 10 秒，并分别回放两个麦克风。 |
| 按键测试 | 按下并松开 BOOT，查看按键状态、有效按压次数与通过结果。 |

## 硬件需求

开发板和 USB 数据线；配网、天气和小智需要可联网的 2.4 GHz Wi-Fi。音乐来自内置 Flash，录音存放在 PSRAM，无需 SD 卡。

## 怎么运行

直接体验可下载[最新合并固件](../../firmware/README_ZH.md)，从 `0x0` 烧录。编译源码请在 ESP-IDF **v5.5.4** 终端进入本目录，执行：

```sh
idf.py build flash monitor
```

目标为 ESP32-S3，Flash / PSRAM 均为 8 MB，日志波特率为 **2000000**。默认尝试 `weather-wifi` / `12345678`；更换网络可打开“设置 > Connect Wi-Fi”，扫描二维码，或连接屏幕所示热点（密码 `12345678`），浏览器访问 `http://192.168.4.1` 填写自己的网络。

## 预期现象

上电显示桌面，左右滑动切页，点击图标打开 APP；大部分页面通过左上角按钮返回。Mic Test 显示两个独立电平，录音后可分别点击 MIC1 / MIC2 回放；关闭 APP 后录音丢弃。

## 常见问题

音乐、Mic Test 和小智共用音频设备，请退出当前音频 APP 再打开另一项。首次安装须烧录完整合并固件，或执行完整的 `idf.py flash`；仅更新应用 BIN 不会安装分区表和语音模型。
